- Warna utama: #1D3A8C (biru), dipilih karena sederhana, profesional, dan nyaman dilihat.
- Halaman menggunakan token warna, spasi, radius, bayangan, dan ukuran teks agar tampilan konsisten.

### Token yang saya tetapkan

| Token           | Nilai                      | Untuk apa                            |
| --------------- | -------------------------- | ------------------------------------ |
| --color-primary | #1D3A8C                    | warna utama, tombol, tautan, penanda |
| --color-fg      | #0F172A                    | warna teks utama                     |
| --color-bg      | #F8FAFC                    | latar halaman                        |
| --color-focus   | #2563EB                    | garis fokus pada input dan tombol    |
| --space-1       | 0.25rem                    | jarak sangat kecil                   |
| --space-2       | 0.5rem                     | jarak kecil                          |
| --space-3       | 0.75rem                    | jarak antar elemen                   |
| --space-4       | 1rem                       | jarak standar                        |
| --space-6       | 1.5rem                     | jarak antar bagian                   |
| --space-8       | 2rem                       | jarak besar                          |
| --radius-sm     | 0.25rem                    | sudut kecil                          |
| --radius-md     | 0.5rem                     | sudut kartu dan tombol               |
| --shadow-sm     | 0 1px 3px rgb(0 0 0 / 0.1) | bayangan ringan                      |
| --text-sm       | 0.875rem                   | teks kecil                           |
| --text-md       | 1rem                       | teks normal                          |
| --text-xl       | 1.5rem                     | subjudul                             |
| --text-3xl      | 2.25rem                    | judul utama                          |

Kriteria selesai saya: mengubah --color-primary di satu baris harus mengubah warna tombol, tautan, judul, dan garis fokus.
